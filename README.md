# NexTrade | منصة تعليم التداول

منصة عربية احترافية لتعليم التداول من الصفر إلى الاحتراف.

## 🎯 عن المشروع

NexTrade منصة تعليمية متكاملة تعمل على:
- 📱 Android
- 🍎 iOS (عبر PWA)
- 💻 الويب

## ✨ المميزات

- 📚 دورات منظمة للمبتدئين والمتوسطين
- 💡 إشارات تداول مباشرة (XAUUSD)
- 🔔 إشعارات فورية
- 🎥 فيديوهات تعليمية مع تتبع التقدم
- 💳 طرق دفع متعددة
- 🌍 دعم عربي كامل (RTL)

## 🏗️ التقنيات

- Flutter (Android + iOS)
- Next.js (Web)
- NestJS + PostgreSQL (Backend)
